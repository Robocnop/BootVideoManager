First stable release of Boot Video Manager: a real Windows installer, automatic updates, and an interface in English
or French.

## What's new

- **Windows installer**: installs every component (.NET runtime, interface, VLC) into a program folder, creates the
  shortcuts and registers itself in *Windows Settings › Apps* for uninstallation. No administrator rights are
  requested by default; installing for all users is still possible. Uninstalling offers to remove settings and cache,
  without ever touching the videos placed in Steam.
- **Automatic updates**: on startup, the app checks GitHub for a newer version and offers to install it in one click.
  The installer is downloaded, **verified (size and SHA-256 hash)**, then launched; the app closes and restarts on its
  own once updated. You can skip a version or turn off the check in *Settings › Updates*.
- **English / Français**: the language follows Windows, or can be chosen in *Settings › Language*.
- **Single window**: launching the app again brings the already open window to the front.
- **More robust downloads**: an interrupted video resumes where it stopped; two downloads run at the same time and the
  next ones wait their turn ("Queued…").
- **Remembered preferences**: catalog sorting and filters, preview volume and mute (new volume slider).
- **Diagnostic log**: *Settings › About › Open the logs folder*, to attach to a bug report.
- **Windows ARM64**: dedicated installer and portable build.

## Fixes

- The preview's Pause / Play button showed the opposite state.
- Thumbnail memory leaks (quickly filtered catalog, refreshed Installed tab).
- "Unexpected error" when a video disappeared from the folder while the app was reading it.
- Two open windows could interfere with each other when saving settings.
- A failure to save the Steam folder was hidden by the confirmation message.
