Première version stable de Boot Video Manager : un vrai installateur Windows, les mises à jour automatiques et
l'interface en français ou en anglais.

## Nouveautés

- **Installateur Windows** : installe tous les composants (runtime .NET, interface, VLC) dans un dossier de
  programme, crée les raccourcis et s'ajoute à *Paramètres › Applications* pour la désinstallation. Aucun droit
  administrateur demandé par défaut ; l'installation pour tous les utilisateurs reste possible. La désinstallation
  propose de supprimer les réglages et le cache, sans jamais toucher aux vidéos placées dans Steam.
- **Mises à jour automatiques** : au démarrage, l'application vérifie s'il existe une version plus récente sur
  GitHub et propose de l'installer en un clic. L'installateur est téléchargé, **vérifié (taille et empreinte
  SHA-256)**, puis lancé ; l'application se ferme et redémarre toute seule une fois à jour. Possibilité d'ignorer une
  version ou de désactiver la vérification dans *Réglages › Mises à jour*.
- **Français / English** : langue automatique selon Windows, ou au choix dans *Réglages › Langue*.
- **Une seule fenêtre** : relancer l'application ramène la fenêtre déjà ouverte au premier plan.
- **Téléchargements plus robustes** : une vidéo interrompue reprend là où elle s'était arrêtée ; deux
  téléchargements tournent en même temps, les suivants attendent leur tour (« En attente… »).
- **Préférences mémorisées** : tri et filtres du catalogue, volume et son coupé de l'aperçu (nouveau curseur de
  volume).
- **Journal de diagnostic** : *Réglages › À propos › Ouvrir le dossier des journaux*, à joindre à un signalement.
- **Windows ARM64** : installateur et version portable dédiés.

## Corrections

- Le bouton Pause / Lecture de l'aperçu affichait l'état inverse.
- Fuites de mémoire des miniatures (catalogue filtré rapidement, onglet Installées actualisé).
- « Erreur inattendue » quand une vidéo disparaissait du dossier pendant sa lecture par l'application.
- Deux fenêtres ouvertes pouvaient se gêner en enregistrant les réglages.
- Un échec d'enregistrement du dossier Steam était masqué par le message de confirmation.

## Téléchargements

| Fichier | Pour qui |
|---|---|
| `BootVideoManager-1.0.0-win-x64-setup.exe` | **Windows 10/11 (recommandé)** : installateur |
| `BootVideoManager-1.0.0-win-arm64-setup.exe` | Windows sur processeur ARM (Snapdragon…) |
| `BootVideoManager-1.0.0-win-x64-portable.exe` | Windows, sans installation (pas de mise à jour automatique) |
| `BootVideoManager-1.0.0-win-arm64-portable.exe` | Windows ARM, sans installation |
| `BootVideoManager-1.0.0-linux-x64.tar.gz` | Linux x64 (non testé sur matériel réel) |
| `SHA256SUMS.txt` | Empreintes de tous les fichiers |

L'exécutable n'est pas signé : Windows SmartScreen peut afficher un avertissement. Cliquez sur « Informations
complémentaires », puis « Exécuter quand même ».

Depuis une version 0.x portable : installez simplement la 1.0.0 avec l'installateur, vos réglages et vos vidéos sont
conservés.
