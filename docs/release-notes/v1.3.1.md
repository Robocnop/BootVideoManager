The Linux package now keeps itself up to date.

## What's new

- **Automatic updates on Linux.** The Flatpak package now comes from a signed repository hosted with the project
  (robocnop.github.io/BootVideoManager). Install it once, from the [install page](https://robocnop.github.io/BootVideoManager/)
  or with the `.flatpak` file below, and your software center (Linux Mint's Software Manager, Discover, GNOME
  Software…) or `flatpak update` offers every new release, like for any other app.
- The Flatpak copy explains in *Settings › Updates* where its updates come from.

If you installed the 1.3.0 `.flatpak`, install this one over it once (`flatpak install --user --reinstall
BootVideoManager-1.3.1-x86_64.flatpak`): 1.3.0 did not know where to look for updates yet.
